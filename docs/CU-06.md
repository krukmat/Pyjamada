# CU-06 — Configure Game

## Goal
Allow the player to configure the minimal runtime/application settings needed to evaluate the Android V1 experience.

## Implemented settings
- Audio enabled: ON/OFF.
- Music volume: 0–100% in 10% increments.
- SFX volume: 0–100% in 10% increments.
- Touch controls: `standard` or `mirrored` layout.

## Persistence boundary
Settings are intentionally independent from `GameState` and the single game save.

```text
SettingsScreen
   ↓
UpdateGameSettingsUseCase
   ↓
GameSettingsPort
   ↓
AsyncStorageGameSettingsRepository
   ↓
pyjamada:v1:settings
```

The game save remains under its separate repository/key.

## Main flow
1. Player selects **SETTINGS** from the main menu.
2. Current settings are displayed.
3. Player modifies one or more values.
4. Each accepted value is persisted immediately.
5. Player returns to the menu.
6. Settings survive application restart.
7. Touch-control layout is applied to CU-03 gameplay presentation.

## Safe fallback
- Missing settings use stable defaults.
- Malformed settings use stable defaults.
- Unsupported schema versions use stable defaults.
- Volume values produced by the domain patch function are clamped to `0..1` and rounded to 10% increments.

## Acceptance coverage
- [x] Audio ON/OFF setting.
- [x] Music volume setting.
- [x] SFX volume setting.
- [x] Basic touch-control configuration.
- [x] Settings persist independently of game-save state.
- [x] Invalid stored settings fall back safely.
- [x] Touch-control setting has a visible effect on the CU-03 control layout.

## Deliberately deferred
- Source-faithful audio playback/content.
- Complex control remapping.
- Gamepad configuration.
- Multiple skins/layout systems.
- Premium visual filters.
- Localization framework.
- Full accessibility suite.

Persisting audio preferences in CU-06 does not claim that the audio runtime itself has been implemented; that remains outside this V1 slice.
