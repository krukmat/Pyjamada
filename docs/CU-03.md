# CU-03 — Minimal Vertical Slice Gameplay

## Goal
Validate the minimum representative gameplay architecture before considering a broader port.

## Implemented slice
- 3 small logical rooms rendered at 128×128 through React Native Skia.
- Left/right touch movement.
- Locked-door collision boundary in room-01.
- One collectible key.
- Minimal inventory (`bedroom-key`).
- ACTION interaction that consumes the key and sets `bedroomDoorUnlocked`.
- Room transitions room-01 → room-02 → room-03, with reverse transitions for rooms 02/03.
- `verticalSliceReached` progression flag on first arrival at room-03.
- State persisted after every input through the existing CU-05 supporting capability.
- Temporary geometric art only; no copied Pyjamarama assets.
